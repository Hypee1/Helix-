# Helix-
Realistic fight game web
Ecco tutti i comandi di HELIX.

Movimento

W A S D: muoversi
Shift (tenuto, andando avanti): correre, consuma fiato
Spazio: saltare
C o Ctrl: accovacciarsi
Q / E: sporgersi a sinistra / destra
Mouse: guardarsi intorno

Armi

1: pugni
2: pistola 9 mm

Con i pugni

Tasto sinistro: pugno, alterna sinistro e destro
Tasto sinistro + mouse di lato: gancio
Tasto sinistro + mouse verso l’alto: montante
Tasto destro (tenuto): guardia, riduce i colpi che ricevi
F: calcio frontale, funziona anche con la pistola in mano

Con la pistola

Tasto sinistro: sparare
Tasto destro (tenuto): mirare dal mirino
R: ricaricare

Pannello e bersaglio

H: cambiare scheda (Organi → Scheletro → Vasi → Nervi)
Tab: cambiare l’avversario di cui vedi i dati

Gioco

V: rallentatore sì/no
T: cambiare orario (giorno → tramonto → notte)
N: nuovo round, ricomincia con gli avversari nuovi
Esc: pausa e menu delle impostazioni

Nel menu (con Esc) puoi cambiare il numero di avversari (1–5), il loro comportamento, orario, grafica, sensibilità del mouse, campo visivo, volume delle voci e munizioni infinite.
